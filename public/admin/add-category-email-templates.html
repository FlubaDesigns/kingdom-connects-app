Add Category Suggestion Email Templates

This utility adds 3 email templates for the category suggestion workflow:

  1. category_suggestion_received - Sent when user submits a suggestion
  2. category_suggestion_approved - Sent when admin approves
  3. category_suggestion_rejected - Sent when admin rejects
